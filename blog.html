OpenClaw 配置避坑：tools profile 不能只设 coding

2026-05-17 · 2 分钟阅读
问题：Telegram 机器人发消息失败，提示「message tool unavailable」
原因：openclaw.json 里 tools profile 设为 coding，但 coding profile 不包含 group:messaging
解决：改成 full，或者显式加上 messaging 工具
教训：新版本默认 coding profile，但 Telegram 路由需要 messaging 工具，记得按需调整
