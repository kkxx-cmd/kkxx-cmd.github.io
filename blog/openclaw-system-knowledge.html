OpenClaw 系统知识库

2026-05-12 · 更新于 2026-05-23 · OpenClaw系统架构CLI

核心架构

Gateway：持久化后台服务，管理所有 agent 生命周期、cron、channel 连接

Agent：运行在 session 中，每次对话是一个独立 session

Channel：连接外部消息平台（Telegram/Discord 等），通过 Gateway 路由

工具 (Tools)：Agent 可调用的能力（exec/web_search/memory 等）

MCP (Model Context Protocol)：扩展工具能力的插件体系

工作目录

工作区：~/.openclaw/workspace/

配置目录：~/.openclaw/

Cron 状态：~/.openclaw/cron/jobs.json + jobs-state.json

关键配置命令

openclaw config get        # 读取配置
openclaw config set   # 写入配置
openclaw doctor                 # 自动诊断修复
openclaw gateway restart        # 重启 Gateway

排查标准流程（2分钟内）

openclaw status
openclaw gateway status
openclaw gateway probe
openclaw doctor
openclaw channels status --probe
openclaw logs --follow

定时任务 (Cron)

isolated：独立 session，每次全新上下文（推荐）

main：在主会话中触发（心跳模式）

session:xxx：持久化命名 session，跨次运行保留上下文

重试：瞬时错误指数退避（30s→60m），最多3次

重要：isolated run 如果只返回 NO_REPLY，不会向 chat 发消息

心跳 (Heartbeat)

主会话定期轮询，不是独立 task。HEARTBEAT.md 存在但空 → 跳过检查（quiet）。quiet hours 外才发检查。用 heartbeat 做轻量轮询比 cron 更合适。

Session 和内存

MEMORY.md 只注入主 session，不注入子代理/群组 session（安全）。每日 memory 文件（memory/YYYY-MM-DD.md）默认不注入，按需读取。上下文窗口紧张时用 memory_search / memory_get 按需加载。

Session Pruning：超长 session 自动压缩，保留关键系统上下文。

工具 (Tools)

exec：宿主机命令，security/full（无审批）/ deny / allowlist。ask 配置：on（每次问）/ off（从不问）/ on-miss（白名单漏的才问）。突然要审批 → 检查 tools.exec.host / security / ask 是否变了。

流式输出 (Streaming)

partial：单一预览消息持续更新（推荐 Telegram）

block：按块更新预览

progress：状态草稿 + 最终答案（工具运行时显示 Thinking... 等）

配对 (Pairing)

Telegram：dmPolicy: "pairing" → 用配对码批准。openclaw pairing list telegram → approve 。配对码 8 位，1 小时过期。

子代理 (Subagent)

sessions_spawn(mode=run)：一次性后台任务。context:"fork"：继承当前 transcript；context:"isolated"（默认）：干净 session。编排多步骤任务用 sessions_spawn + sessions_yield 等待结果。

承诺追踪 (Commitments)

opt-in 功能，对话中推断出的后续跟进承诺。通过 heartbeat 送达，不打扰立即发送。不是 reminders，是"自然对话创造的检查机会"。

文档位置

本地文档：~/.npm-global/lib/node_modules/openclaw/docs/

在线文档：https://docs.openclaw.ai

CLI 命令参考

openclaw setup / onboard / configure

openclaw setup                      # 初始化配置 + 工作区（不跑引导）
openclaw onboard                    # 完整引导流程（gateway/模型/渠道/skill/健康检查）
openclaw onboard --non-interactive  # 非交互式
openclaw configure                  # 交互式配置
openclaw configure --section model  # 只配置某个部分

openclaw doctor

openclaw doctor                     # 检查 + 引导修复
openclaw doctor --fix               # 自动修复
openclaw doctor --lint              # 只读检查（CI用）
openclaw doctor --lint --json       # JSON 格式输出
openclaw doctor --deep              # 深度扫描（检查额外 gateway 安装）
openclaw doctor --generate-gateway-token  # 生成 gateway token
openclaw doctor --only        # 只检查指定项
openclaw doctor --skip        # 跳过指定项

Doctor 检查项包括：gateway.mode 设置、skill 环境依赖、gateway 服务状态、Telegram/Discord 凭证 env 回退、过时 cron 格式迁移（v1→v2）、openai-codex→openai 模型引用修复等。

openclaw plugins

openclaw plugins list               # 列出已安装插件
openclaw plugins search      # 搜索 ClawHub
openclaw plugins install       # 安装（npm 默认）
openclaw plugins install clawhub:  # 从 ClawHub 安装
openclaw plugins install git:github.com//  # 从 git 安装
openclaw plugins inspect        # 查看插件详情
openclaw plugins enable         # 启用
openclaw plugins disable        # 禁用
openclaw plugins uninstall       # 卸载
openclaw plugins update         # 更新
openclaw plugins doctor             # 插件健康检查

安装来源格式：npm: / clawhub: / git: / / @

注意：旧插件格式（无 openclaw.extensions 字段）会安装失败。

openclaw skills

openclaw skills search       # 搜索 ClawHub skills
openclaw skills install       # 安装到 workspace
openclaw skills install  --global  # 安装到全局共享目录
openclaw skills list                 # 列出本地 skills
openclaw skills info          # 查看 skill 详情
openclaw skills check               # 检查 skill 就绪状态
openclaw skills check --agent   # 检查特定 agent 的 skills

openclaw cron

openclaw cron list                  # 列出所有定时任务
openclaw cron get           # 查看任务详情（JSON）
openclaw cron show          # 查看任务详情（人类可读）
openclaw cron add ...               # 创建任务
openclaw cron edit  ...     # 编辑任务
openclaw cron rm            # 删除任务
openclaw cron run           # 手动触发
openclaw cron run  --wait   # 等待执行完成
openclaw cron runs --id     # 查看运行历史

openclaw tasks

openclaw tasks list                 # 列出后台任务
openclaw tasks show             # 查看任务详情
openclaw tasks cancel          # 取消任务
openclaw tasks audit               # 审计异常任务
openclaw tasks maintenance          # 清理/修复任务状态
openclaw tasks flow list            # Task Flow 列表

openclaw gateway

openclaw gateway run                # 前台运行
openclaw gateway start             # 启动服务
openclaw gateway stop              # 停止服务
openclaw gateway restart            # 重启
openclaw gateway restart --safe     # 安全重启（等活跃任务结束后）
openclaw gateway status            # 服务状态
openclaw gateway probe              # 探测连通性
openclaw gateway health            # 健康检查
openclaw gateway install           # 安装为系统服务
openclaw gateway uninstall         # 卸载服务

SIGUSR1 触发热重启（需 commands.restart: true，默认开启）

健康检查端点：/healthz（存活探针）、/readyz（就绪探针，更严格）

openclaw update

openclaw update                     # 更新到最新版
openclaw update --channel beta     # 切换到 beta 频道
openclaw update --channel stable    # 切换到 stable 频道
openclaw update status             # 查看更新状态
openclaw update --dry-run           # 预览（不实际更新）

包管理器安装：npm update -g openclaw / pnpm update -g openclaw

源码安装流程：验证 clean worktree → 切换 channel → preflight build（dev）→ 依赖安装 → 构建 Control UI → 运行 doctor → 同步 plugins

注意：降级需要确认；Nix 模式下禁止 openclaw update；--no-restart 跳过服务重启

全局参数

--dev              # 使用 ~/.openclaw-dev 目录
--profile    # 使用 ~/.openclaw- 目录
--json             # 输出 JSON 格式
--no-color         # 禁用 ANSI 颜色
-V/--version       # 显示版本
