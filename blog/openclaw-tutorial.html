OpenClaw 使用教程

2026-05-17 · 10 分钟阅读 · OpenClaw教程

安装与初始化

npm install -g openclaw
openclaw init
openclaw gateway start

启动后访问 TUI 界面或 Web UI 进行初始配置。Telegram 接入需要先在 openclaw.json 配置 channel 账号。

核心命令

openclaw status              # 查看状态
openclaw doctor               # 自动诊断+修复（有问题先跑这个）
openclaw doctor --repair       # 自动修复
openclaw gateway restart      # 重启 Gateway
openclaw gateway restart --safe  # 智能重启，等任务结束后重启
openclaw logs --follow         # 查看日志
openclaw config get       # 读取配置
openclaw config set   # 写入配置

配置详解

模型配置

配置文件：~/.openclaw/agents/main/agent/models.json

每个 provider 包含 API 端点、认证信息和模型列表。推荐使用 custom-integrate-api 类型接入自有模型服务。

工具权限（重要）

tools.profile 决定可用工具范围：

  • coding：只包含编码工具，不含 messaging（Telegram 机器人不能用）
  • full：全部工具（含 messaging），适合需要发消息的机器人
⚠️ 踩坑记录
如果 Telegram 发消息报「message tool unavailable」，检查 tools.profile 是否设成了 coding，改成 full 即可。

Telegram 配置

{
  "channels": {
    "telegram": {
      "dmPolicy": "pairing",
      "streaming": { "mode": "partial" }
    }
  }
}

dmPolicy: "pairing" 开启配对码验证：新设备发消息后会收到配对码，用 openclaw pairing approve 审批。

定时任务（Cron）

推荐用 sessionTarget: "isolated" 创建独立 session 的后台任务：

openclaw cron add \
  --name "系统状态汇报" \
  --schedule "0 */4 * * *" \
  --session-target isolated \
  --payload-kind agentTurn \
  --payload-message "执行 sys-status.sh 并发送到 Telegram"
💡 推荐做法
定时任务尽量用 isolated session，每次全新上下文，不污染主会话。一次性提醒用 cron at，定期任务用 cron 表达式。

工作区文件说明

工作区：~/.openclaw/workspace/

  • AGENTS.md — 工作区规则、Red Lines、操作边界
  • SOUL.md — 人格、语气、风格定义
  • USER.md — 用户信息（称呼、时区、Telegram ID）
  • MEMORY.md — 长期记忆，只在主会话加载
  • HEARTBEAT.md — 心跳任务清单，运行时定期检查
  • memory/YYYY-MM-DD.md — 每日原始日志

故障排查顺序

1. openclaw doctor --repair   # 自动修复大部分问题
2. openclaw status            # 看整体状态
3. openclaw logs --follow      # 实时看日志
4. openclaw gateway probe     # 检查 Gateway 连通性

Session 管理

每个 Telegram 对话是一个独立 session。可以用 openclaw sessions list 查看所有会话，openclaw sessions history 查看某个会话的历史。

Session 接近上下文上限时会自动 compact（压缩旧消息为摘要）和 prune（清理旧的 tool results）。

插件与扩展

openclaw plugins list        # 查看已安装插件
openclaw plugins install   # 安装插件

插件需要 package.json 含 openclaw.extensions 字段才能识别。安装后用 openclaw doctor 确认加载正常。

内存与记忆

记忆靠文件不靠"心理记住"。每天的 memory 文件是原始素材，凌晨的 dreaming 任务是加工过程，MEMORY.md 是最终成品。

可以用 memory_search 工具搜索历史记忆，也可以直接编辑 memory/YYYY-MM-DD.md 添加记录。
