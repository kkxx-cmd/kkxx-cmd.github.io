OpenClaw 核心概念

2026-05-12 · 8 分钟阅读 · OpenClaw概念

Agent 与工作区

Agent 是持有身份、工具和会话的会话实体，不是进程或线程。通过模型推理响应消息，使用工具执行操作，通过 channel 发送回复。

工作区默认路径：~/.openclaw/workspace/，与 ~/.openclaw/ 配置目录分离。

启动文件（按加载顺序）：AGENTS.md → SOUL.md → USER.md → MEMORY.md → TOOLS.md → HEARTBEAT.md

Agent Loop 完整生命周期

intake → context assembly → model inference → tool execution → streaming → persistence

1. intake：接收 inbound message，进行 dedupe、debounce

2. context assembly：组装 system prompt + SOUL.md + AGENTS.md + workspace 文件 + session 历史 + memory + tool results

3. model inference：调用 LLM，返回 text_delta/events

4. tool execution：解析 tool call，执行工具

5. streaming：分块发送 reply

6. persistence：保存 session transcript，触发 compaction 检查

Session 管理

DM scope：控制多设备消息是否共享同一 session

"main"：所有 DM 共享一个 session（默认）

"per-channel-peer"：每个 channel+peer 独立 session（推荐）

Session Pruning：仅修剪 old tool results，不修改磁盘 session transcript。全量历史始终保留。

Compaction：当对话接近 context 限制时，将旧消息压缩为摘要。pruning 裁 tool results（内存级），compaction 摘要整段对话（落盘）。

Memory 系统

MEMORY.md：长期记忆，curated distilled notes，仅主会话加载

memory/YYYY-MM-DD.md：每日原始日志，自动创建，按需读取

基于 SQLite FTS5（全文搜索）+ 向量搜索，支持 hybrid search

Commitments（推断承诺）

介于 memory 和 automation 之间。在 agent reply 后运行 hidden extraction pass，识别隐式 future check-in。通过 heartbeat 投递，commitments.maxPerDay 限制每天投递数（默认 3）。

不等同于 Reminders：exact reminders 走 cron jobs，隐式 follow-up 走 commitments。

多 Agent 系统

每个 agent 是隔离的（isolated sessions）。通过 bindings 将 channel message 路由到特定 agent，每个 agent 有自己独立的 agentDir（独立 workspace）。

命令队列与调度

steer   → 尝试合并到当前运行，超时入队（默认 500ms debounce）
followup → 直接作为 follow-up turn 加入当前运行
collect  → 批量收集多个消息后一次性处理
interrupt → 中断当前运行，立即处理

Streaming 与分块

Preview Streaming（消息编辑更新）：适用于 Telegram/Discord/Slack

partial：单次 preview，实时替换（推荐 Telegram）

block：分块/追加更新

progress：进度状态，结束时发最终答案

重要设计原则

Memory is files：session 结束后靠文件续命，不靠"心理记住"
Pruning + Compaction 互补：pruning 管 tool results（内存级），compaction 管 conversation summary（落盘）
Commitments ≠ Reminders：exact reminders 走 cron jobs，隐式 follow-up 走 commitments
SOUL.md > AGENTS.md for voice：人格定义在 SOUL.md，规则写在 AGENTS.md
